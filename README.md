# analisis-exo-planetas
Se hizo un análisis riguroso sobre  variables cuantitativas que determinan las características de exoplanetas como: temperatura, densidad estelar, metalicidad, etc. El análisis de estas variables permitió verificar comportamientos, relaciones intrínsecas entre  las mismas, reafirmación de hipótesis y modelos astronómicos ya publicados.
